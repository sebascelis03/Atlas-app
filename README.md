# 🏋️ ATLAS — Fitness & Workout Tracker (JavaScript → APK)

Aplicación móvil de entrenamiento de fuerza, 100 % local, construida con JavaScript, Vite y Capacitor para exportar un instalador `.apk`.

> La versión académica original en Kotlin / Android Studio se conserva en la rama `main` y en el tag `v1.0-kotlin-academico`.

## Documentación
Toda la documentación vive en [`.docs/`](.docs/) (fuente única de verdad):
reglas, documento maestro, referencia visual, bitácora de decisiones, tareas y planes de implementación.

## Requisitos
* Node.js 20 o superior
* (Para generar el `.apk`, a partir del Plan #10) Android SDK y JDK

## Comandos
```bash
npm install       # instalar dependencias
npm run dev       # servidor de desarrollo (http://localhost:5173)
npm run build     # compilación de producción en dist/
npm run preview   # previsualizar dist/
```
